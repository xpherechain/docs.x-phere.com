## Hardware Requirements

### Minimum Specifications

- **CPU**: 4+ cores
- **RAM**: 4GB minimum
- **Storage**: 50GB+ SSD
- **Network**: Stable internet connection (10Mbps minimum)

### Recommended Specifications

- **CPU**: 8+ cores
- **RAM**: 8GB or higher
- **Storage**: 100GB+ NVMe SSD
- **Network**: High-speed internet connection (50Mbps+)

## Software Requirements

### Operating System

- **Windows**: Windows 10 64-bit or higher
- **MacOS**: macOS Catalina (10.15) or higher
- **Linux**: Ubuntu 20.04 LTS or higher

### Required Software

- Go 1.22 or higher

## Wallet Requirements

- Zigap wallet account
