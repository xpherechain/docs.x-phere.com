# Governance

## Union Governance

Governance participation is one of the [Union](/union)'s core responsibilities, alongside block
validation and reward distribution. The voting rule published today is:

| Rule | Detail |
|------|--------|
| Voting weight | **One vote per member** — not one vote per slot. A member holding several slots still casts a single vote. |
| Tie-break | Where a vote is tied, the **XPHERE Foundation** casts the **tie-breaking vote**. |

Holding multiple slots increases proposer turns and reward share, not voting power. See
[XPHERE Union](/union) for the membership structure these votes belong to, and
[Members](/union/members) for the current slot distribution.

:::note Wider governance framework not yet published
Beyond Union voting, a wider governance framework — community proposals and on-chain voting — has
**not yet been published**. This page will carry it once the Foundation finalizes it. Until then, no
process, threshold, or timeline for it should be inferred.
:::
